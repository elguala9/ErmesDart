# ErmesDart Project Overview

## Project Purpose
ErmesDart is a Dart monorepo project using Melos for workspace management. It appears to be a domain-driven architecture with core logic, data layer, and multiple specialized packages.

## Monorepo Structure
- **packages/iermes** - Main interface/entry point package
- **packages/ermes_core** - Core domain logic and models
- **packages/ermes_storage** - Storage/persistence layer
- **packages/ermes_signaling** - Signaling/communication layer
- **packages/ermes_test** - Testing utilities and test suites
- **packages/types** - Type definitions

## Tech Stack
- Dart SDK >=3.9.4 <5.0.0
- Melos v7.3.0 for workspace management
- build_runner for code generation
- dart test framework
- Includes testing utilities

## Key Commands
- `melos bootstrap` - Install all dependencies
- `melos run test` - Run all tests
- `melos run test:interfaces` - Run interface compliance tests
- `melos run analyze` - Check code quality
- `melos run format` - Format code
- `melos run ci` - Full CI pipeline

## Code Style
- Dart analyzer with strict settings (--fatal-infos in full analysis)
- Format checking before commit
- Interface compliance tests available

## Cipher & Signer Factories (NEW)
Created factory functions for KeyInfo-based cipher and signer creation:
- **`createCipher(KeyInfo)`** - Creates ISymmetricCipher (AES, ChaCha20, DES)
- **`createSigner(KeyInfo)`** - Creates ISigner (Ed25519, ECDSA P-256/384/521, RSA-PSS/PKCS1v15)
- Located in: `packages/ermes_cipher/lib/src/factories/ermes_cipher_factories.dart`
- Signer implementations in: `packages/ermes_cipher/lib/src/signer/`
- Documentation: `packages/ermes_cipher/FACTORY_USAGE.md`
- Algorithm detection: Converts CryptoAlgorithm enum to lowercase string and checks keywords
- Signer classes are final, extend CryptDartSigner (base class), implement ISigner interface
- Current signer implementations are placeholder stubs - throw UnimplementedError (ready for user implementation)

## Important Notes
- Project has barrel files (indexes) generated by build_runner
- Uses path dependencies between packages in monorepo
- Interface tests are a key quality metric
- Testing infrastructure is well-developed (ermes_test package)
- Barrel files use barrel_files_annotation package for marking exports with @includeInBarrelFile
- DataEncrypted type is now exported from iermes package (added to lib/iermes.dart)
